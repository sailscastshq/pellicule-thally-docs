---
title: Make your first video
description: Give your coding agent a short brief, then watch your first MP4.
---
Make a three-second video with a title that fades in. You describe it; your coding agent creates the scene and renders an MP4.

You need a coding agent that can edit files and run terminal commands, such as Codex, Claude Code or Cursor. Have Node.js with npm and FFmpeg available on your machine.

## 1. Install the Pellicule skill

Open a project folder in your agent and run:

```bash
npx skills add sailscastshq/pellicule/skills
```

Choose your agent in the installer. The skill gives it Pellicule's setup, animation and rendering instructions. Start a fresh agent session in that folder if it cannot see the new skill.

## 2. Describe your video

Send your agent this prompt:

```text
Use the pellicule skill to make a three-second video that says
“Hello, video.” on a dark background. Fade the title in, then hold it.
Render an MP4 at 1280 × 720 and 30 fps. Show me the local file when
it is ready. Do not upload or publish it.
```

Your agent handles the project, Vue component and render command. If a tool is missing, have it explain what is needed before continuing. You do not need to write Vue yourself.

## 3. Watch it

Open the MP4 your agent returns. Check that the title fades in and the clip lasts three seconds. Then change the words, colors or movement in your prompt and ask for another render.

[Watch a tested three-second example](/examples/first-video.mp4). Your agent's design may differ; the useful result is your own playable video.

## If you get stuck

- **Skill not found:** confirm installation completed for this agent, then start a new session in the same folder.
- **Missing tools:** ask the agent to check Node.js, FFmpeg and Playwright Chromium, and report the missing prerequisite.
- **Render fails:** give the agent the actual error and ask it to resolve that error before claiming success.
