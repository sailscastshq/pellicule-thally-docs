title: Make your first video
description: Give your agent the Pellicule skill and a brief. Get a rendered MP4.
---
Make a three-second title card with a fade-in and a short upward movement. Your agent handles the Vue code and the render; you review the result.

## 1. Open a project folder

Open an empty folder in a coding agent that can edit local files and run terminal commands. You need Node.js with npm and FFmpeg available on your machine. Your agent will check them before rendering.

This walkthrough was verified on macOS with Node.js 24.14.1 and FFmpeg 8.0.1.

## 2. Install the Pellicule skill

In that folder, run the command from [Pellicule's official skill instructions](https://github.com/sailscastshq/pellicule/tree/main/skills):

```bash
npx skills add sailscastshq/pellicule/skills
```

Choose your agent in the installer. For Codex, this noninteractive variant was also tested:

```bash
npx --yes skills add sailscastshq/pellicule/skills --agent codex --yes
```

The installer should report that the `pellicule` skill is installed. Open a fresh agent session in the same folder if the skill is not visible to your current session. Tell your agent to use it explicitly.

## 3. Give your agent this brief

Copy this into your agent:

```text
Use the installed pellicule skill to make my first video.

Check Node.js, npm, and FFmpeg first. If FFmpeg is missing, tell me what
is needed before continuing; do not install system software for me.

Work in a new first-video subfolder. Initialize an npm project and install
pellicule@0.4.0 and vue@3.5.43 with --save-exact. Install Playwright Chromium
with npx playwright install chromium if needed.

Create Video.vue: a 1280 × 720 title card on a dark navy background.
Show “Hello, video.” in large white type with a small green label above it.
Fade the text from invisible to visible and move it upward 24 pixels during
frames 0–20, then hold it. Use system fonts and no remote assets.
Keep all animation driven by Pellicule's frame number.

Render it with:
npx pellicule Video.vue -d 90 -f 30 -w 1280 -h 720 -o first-video.mp4

Check that the file exists and, if FFprobe is available, verify 90 frames,
30 fps, 1280 × 720, and a three-second duration. Give me the local file path
and summarize what you actually verified. Do not upload or publish it.
```

The skill teaches the agent how to write the component and render it. You can change the words or colors in the brief without learning Vue first.

## 4. Review your video

Open the `first-video.mp4` path your agent returns. The title should fade and settle into place during the first second, then remain visible until the clip ends.

## If you get stuck

- **The agent cannot see the skill:** confirm installation completed in this project folder, start a fresh session there, and ask it to use `pellicule`.
- **FFmpeg is missing:** install it for your operating system, then ask your agent to check `ffmpeg -version` again.
- **Chromium is missing:** ask the agent to run `npx playwright install chromium` inside the video project.
- **The render fails:** paste the actual error back to your agent. It should report the failed command and resolve that error before claiming success.

Next, [ask for a longer version or a different format](/guides/timing-and-output). The [manual guide](/guides/edit-the-source) is available if you want to inspect or edit the code yourself.
