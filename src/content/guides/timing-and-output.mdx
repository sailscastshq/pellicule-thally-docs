title: Adjust timing and sound
description: Export a six-second logo reveal from the full film, then control timing and audio deliberately.

This optional guide uses the 30-second film on the [homepage](/), separate from the simple [first-video quickstart](/quickstart). Export its opening as a short logo reveal, then adjust timing and sound.

## Open the showcase project

[Download the complete showcase project](/examples/pellicule-first-video.zip), extract it, and open its folder in a terminal. With Node.js and FFmpeg available, run:

```bash
npm ci
npx playwright install chromium --only-shell
node make-sound.mjs
npx pellicule Video.vue -d 900 -f 30 -w 1280 -h 720 -a soundtrack.wav -o pellicule-intro.mp4
```

The project includes the Vue scene, original score generator, locked dependencies, artwork and credits. This full command was tested from a fresh extraction; the result is the film shown on the homepage.

## Export just the logo reveal

From the folder containing `Video.vue` and `soundtrack.wav`, make a six-second soundtrack with a one-second fade, then render:

```bash
ffmpeg -y -i soundtrack.wav -t 6 -af afade=t=out:st=5:d=1 logo-sound.wav
npx pellicule Video.vue -d 900 -r 0:180 -f 30 -w 1280 -h 720 -a logo-sound.wav -o logo-reveal.mp4
```

`-d 900` keeps the full scene's frame range. `-r 0:180` captures frames 0–179, giving you six seconds at 30 fps. The bars still become the `ll` in the wordmark at the same speed; the later scenes are simply left out. Because this range starts at zero, the soundtrack begins at the same point as the full film. The FFmpeg step shortens the score and fades it out before the cut.

In the tested Pellicule 0.4.0 release, passing the full 30-second WAV to this short frame range kept the MP4 container at 30 seconds, even though it had only 180 video frames. Trimming the sound first makes the delivered file six seconds long.

[Watch the tested six-second version](/examples/logo-reveal.mp4). To confirm your output:

```bash
ffprobe -v error -show_entries stream=codec_type,codec_name,nb_frames,r_frame_rate -show_entries format=duration -of json logo-reveal.mp4
```

Expect H.264 video, 180 video frames, `30/1` fps, an AAC audio stream and a duration of six seconds.

## Change the words without changing the timing

Open `Video.vue`. In the second scene, replace `Make an idea` with `Make your story`. Keep the second line, `move.`, short. Render the opening range to check the logo, then render the full film to review the changed scene.

A coding agent can make this edit if you prefer. Tell it which text to change, which timing to preserve, and which output to render. The [source guide](/guides/edit-the-source) explains the frame ranges.

## Use frames, not wall-clock time

At 30 fps:

```text
frames = seconds × 30
seconds = frames ÷ 30
```

The opening morph uses frames 40–100, so it lasts two seconds. Changing the output to 60 fps without changing those frame numbers would make that motion last one second. To preserve the timing at another frame rate, scale **all** scene boundaries and animation ranges, not just the output duration. The supplied renders use 30 fps; a 60-fps adaptation is not claimed as tested.

Avoid `setTimeout`, current timestamps and unseeded randomness in the component. Pellicule may render a frame faster or slower than playback; the frame number must determine what appears.

## Change or remove the sound

The soundtrack is made by `make-sound.mjs`. The first four `note` calls define the opening phrase; their first argument is the start time in seconds. Keep those starts aligned with the reveal, then run the script again and rerender.

To make a silent version, omit the audio flag:

```bash
npx pellicule Video.vue -d 900 -r 0:180 -f 30 -w 1280 -h 720 -o logo-reveal-silent.mp4
```

For your own WAV or MP3, replace `soundtrack.wav` after checking your rights to use it. For a different output duration, prepare the audio to that duration explicitly; do not assume this tested version will trim a longer track. This example's original synthesized score and its generator are included under the [example license](/examples/LICENSE.txt); the Pellicule mark remains brand artwork.

## Troubleshoot the result

| Result | Likely next step |
| --- | --- |
| Six-second file contains a later scene | Check that the range is `0:180`, not a later start frame. |
| Animation speeds up after changing fps | Scale every frame-based boundary, or return to 30 fps. |
| File duration is longer than the captured frames | Check the audio duration. Trim and fade the WAV to match before rendering. |
| Sound ends abruptly | Fade the sound source before the cut, then rerender. A frame range does not rearrange the score. |
| Audio changes do not appear | Regenerate `soundtrack.wav`, then render a new MP4; changing the script alone does not update either file. |
| Text wraps or clips in another format | This scene is composed for 1280 × 720. Reposition and resize elements before exporting a portrait layout. |

Run `npx pellicule --help` for the flags supported by your installed version. For integrating with an existing app, use the [official Pellicule documentation](https://docs.sailscasts.com/pellicule).
