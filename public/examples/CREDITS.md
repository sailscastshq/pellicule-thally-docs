# Credits

The component animates Pellicule's user-approved wordmark geometry: two green bars form the letters `ll` in `pellicule`. Green: `#42B883`. The companion `pellicule-wordmark.svg` is the same artwork used in these docs. Brand names and marks belong to their respective owners.

The score is original synthesized audio created for this example with `make-sound.mjs`. It contains no third-party recordings, samples or copied sound logo. You may reuse or modify the synthesis script and generated audio under the MIT license included with this example. No attribution is required for the audio.

Typography uses Arial/Helvetica from the rendering machine. No font file is redistributed. Font substitution can change letter shapes and spacing on another operating system. The tested render used macOS.
