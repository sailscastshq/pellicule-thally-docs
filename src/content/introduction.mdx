## From an idea to an MP4

Make a product intro, an announcement, or a reusable video template with a coding agent. Install Pellicule's official skill, describe what you want, and have your agent create and render the video locally.

The skill gives your agent Pellicule's setup, animation, timing, and rendering guidance. Pellicule uses Vue underneath; your agent can write the components for you. You direct the result and review the finished video.

## Start small, then refine

[Make your first video](/quickstart) with a copyable prompt and a three-second output. You need a coding agent that can work with local files and a terminal, Node.js, and FFmpeg. You do not need an existing Vue app.

Then [change the timing and output](/guides/timing-and-output) with follow-up prompts. If you prefer to work directly in code, the [manual example](/guides/edit-the-source) includes the complete tested component.

Pellicule captures frames in a browser and encodes them with FFmpeg. Your project stays editable, so you can ask for another variation without starting over.
