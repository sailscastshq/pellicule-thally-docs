## Who is it for?

Use Pellicule when you want a video you can edit and render again: a product announcement, a logo animation, or a template with changing text and colors.

If you write Vue, you can build the scene directly. If you prefer to describe what you want, a coding agent—an assistant such as Codex, Claude Code or Cursor that edits files and runs commands—can write it for you. Pellicule's official skill gives that assistant the rendering and animation instructions. You do not need Vue experience to follow this guide.

## How does it work?

A Vue component describes what appears in the video. Pellicule renders it in a browser, one frame at a time, then uses FFmpeg to encode those frames into an MP4. The current frame number drives the animation, so you control when each movement starts and stops.

You need Node.js, FFmpeg and a Chromium browser for rendering. There is no existing Vue application to set up for this standalone example.
